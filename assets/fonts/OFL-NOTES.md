# Bundled fonts (SIL Open Font License 1.1, plus one Apache 2.0 — all free for commercial print)

- Fraunces SemiBold (variable) — display serif: headlines, card titles
- Caveat SemiBold — handwriting accent: signatures, annotations (never body)
- Inter Regular/Bold — clean sans: body, captions, small print
- Courier Prime Regular/Bold — typewriter: inside messages with a typed-letter feel

Photo-grid card lettering styles (age numeral + name, typeset; backend/photo_grid.py):
- Anton Regular (OFL) — bold modern
- Graduate Regular (OFL) — sporty varsity
- Great Vibes Regular (OFL) — botanical name script
- Pacifico Regular (OFL) — playful
- Luckiest Guy Regular (Apache License 2.0, commercial-print-safe) — kids

These five came from github.com/google/fonts (ofl/anton, ofl/graduate,
ofl/greatvibes, ofl/pacifico, apache/luckiestguy); their license texts are in
licenses/.

Source: Google Fonts (fonts.google.com). License texts ship with Google
Fonts; keep this file with the fonts. Do not add random TTFs here — every
font in this folder must be OFL or equivalent commercial-print-safe.
