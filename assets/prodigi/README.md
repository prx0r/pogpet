# Prodigi marketing assets (free-to-use, prodigi.com/downloads)

The API gives zero images (product lookup returns sku/description/dims/
attributes only). Listing imagery comes from here instead:

- `classic-greetings/`: 2 lifestyle shots + sheet PDF.
- `kiss-cut-stickers/`: 4 lifestyle shots (laptop/folder/chest/peel) + sheet.
- `magnets/`: 2 nine-sheet shots + sheet.
- `wrapping-paper/`: 3 shots (single/group/box) + sheet.
- `photo-mugs/`: 3 shots + zip kept.
- `Prodigi-Temporary-tattoos.pdf`: spec sheet (no photo zip on its page).
- Notebook/postcard/canvas/tiles/poster pages carry PDFs only — use the
  dashboard 3D mockup generator for those shots (founder session).
- Dashboard-only (founder session needed): per-variant print templates
  with exact print areas (resolves GLOBAL-GRE vs CLASSIC-GRE), 3D mockup
  generator (tattoos, magnets, stickers, cards, wrap roll), per-SKU codes
  for sticker/tattoo/magnet.
