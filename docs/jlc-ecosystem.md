# JLC ecosystem: metal, marking, electronics (single brand)

Saved 2026-10-09. Grimoirer/Glimlings/Muse folded under OddHobb
while testing. JLC3DP (resin/nylon/FDM/metal) + JLCCNC (machine,
engrave, UV) + JLCPCB (flex, assembly) cover the whole arc from
plastic toy to sensor wearable. List prices are entry points, not
landed costs; JLC is a production partner, not turnkey fulfilment.

## Process picks

Metal print (BJ/SLM 316L, Ti): sculptural amulets, seals, enclosures.
$5/$8 starts. Raised/recessed detail ≥1×1mm — too coarse for small
glyphs, so intricate text goes to laser, not geometry. Polishing
optional, not jewellery-grade by default. Skin contact needs finish
docs + nickel/jewellery-reg checks; 316L alone certifies nothing.
CNC + laser/UV: discs, plates, housings, precision fits. 1440dpi UV,
0.03–0.1mm laser depths — the fine-detail lane. PCBs (rigid + flex
1/2/4L, assembly from $8 setup): the Glimlings/Muse core (BLE MCU,
LEDs, haptics, IMU, NFC, LiPo). Phone holds AI/voice/personalisation
first; no always-listening hardware yet. Every object gets a unique
ID (PCB QR/DataMatrix incl. serials) → persistent digital identity.
ID identifies; ownership/auth needs separate design.

## Families

Engraved Seal (CNC disc 30–40mm + laser): fastest test, no
electronics. Sculptural Talisman (BJ/SLM + finish): geometry IS the
identity. Living Amulet (metal + NFC insert): tap-to-open digital
twin; metal needs ferrite/insulator window or on-metal tag. Glimlings
desk companion first (BLE+LED+behaviour), wearables after willingness
to pay is proven. Muse reuses the core + validated sensors. Apparel
rule stands: no metal hardware in product photos until the metal line
is real.

## Parametric thesis

One parameter set → geometric object + digital twin (visualisation,
audio, meaning). Sanskrit phonemes → construction → engraved amulet
→ NFC-linked experience. Same approach scales resin prototype →
steel amulet → interactive wearable.

## Launch order + first batch

Talisman test (£39.99) → NFC amulet (£59.99, passive tag) → math
sculpture (£49.99) → desk companion. Batch: brick on WJP Tough,
medallion on BJ-316L polished, 35mm alu seal on CNC+laser,
parametric object on SLA. Wearables need enclosure assembly, battery
safety, radio compliance, charging, certification before sale.
