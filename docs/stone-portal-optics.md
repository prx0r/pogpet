# Stone × Portal optics (split by physics, united by character)

Saved 2026-10-09. Stone: pocketable, silent, battery — flowing
optical network + tactile pacing, never a projector. Portal:
desktop, animated, conversational — Pepper's Ghost first,
light-field later. Same character state appears on phone, portal,
figurine, eventual hologram. Identity persists; hardware is just
another body.

## Technology verdicts (2026)

Multi-view 3D (Looking Glass Go 6", 100 views, 58°, $199): real
depth + parallax, Blender/Unity/splat workflows. Evaluate ours on
one before committing — cheapest meaningful light-field test.
Pepper's Ghost (veebch/pepper: 3.4" LCD + 90mm dome + acrylic +
print): floating illusion, not true multi-view; magical dark.
Build the $100–250 dock first, test presence before expensive
optics. Volumetric (Voxon $6.8k, GPU PC): specialist only.
Metasurface/SLM holography (160°×160° @60Hz, 2025): lab only.
Mirrors redirect; detail needs a modulated source (display, SLM,
dense emitters).

## Stone optics (waveguides, not projectors)

3D-printed polymer waveguides (ACS 2026): SLA branching structures
redistribute light; smoothing = 3.6× transmittance; branch angle +
curvature + loss characterized. Waveguides transport, never
animate — flow needs independently driven injection points.
Modular light module, not fixed LEDs: main board (BLE, haptics,
power, button, standard light interface) + Optics A (24–36
emitters, tested diffusers) / B (printed resin/PMMA pathways,
zoned emission) / C (multilayer depths). Warm-white channel kept;
exact package TBD by sourcing (side-view RGBW may lose to
top-emit). Haptic-only mode first-class (pocket = invisible
light). Panic mode: instant gentle grounding via button, no
display/AI/breath-holds; aid, never treatment.

## Portal (character dock)

Pi-class host first (pre-rendered OK; interactive 3D needs Pi+),
phone/cloud AI, JLC for PCB/enclosure/mounts (not LCD/optics).
Pipeline: character state → animation/render → optical display →
voice. Reference: veebch/pepper + hologram-system (glTF + hand
tracking + pyramid).
