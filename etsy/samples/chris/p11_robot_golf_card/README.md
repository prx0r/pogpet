# Robot Golf Birthday Card (Chris sample)

OddHobb design card_f8960388b25c431186881a96643fcf67 r1, made through MCP (oddhobb_attach_card_art), with Hark-generated art.

- `01-05_*.jpg`: Etsy listing images, 2000x2000. `listing.txt`: title, price, tags and description.
- `print/`: full-bleed print art (front and back at 1500x2100, inside spread at 3000x2100) plus OddHobb's `print.pdf` export.
- `previews/`: OddHobb's server renders of the front, inside and back.
- `src/`: the clean front art, the stencil source, and the scripts that build the caption, the inside typography and this pack.
