# Brand split — OddHobb owns the identity, Pogtown owns the world

> Saved from the founder conversation. Read with `validatedvision.md`.

## The split

**OddHobb owns the identity. Pogtown owns the world.**

```text
ODDHOBB
"Make someone/something yours"
        │
        ├── create identity
        │     photo → mesh → voice → persona
        │
        ├── make physical things
        │     charms / figures / cards / gifts
        │
        └── bring them to life
                      │
                      ▼
                  POGTOWN
              "Now they exist."
                      │
          ┌───────────┼───────────┐
       Perform       Play       Social
          │             │           │
       comedy       agent games    feed
       music        human vs AI    rooms
       shows        co-op games    sharing
       episodes     competitions   recurring cast
```

OddHobb answers "who/what is this character?" Pogtown answers "what does
this character do once it exists?"

## Onboarding

Starts entirely inside OddHobb. "Make something funny for Dad" → OddHobb
learns Dad, photos, reusable mesh/person record, golf charm, card. Then:

> **Dad's alive now. Want to send him to Pogtown?**

And the same asset becomes physical products, cards, voice, comedy
performer, game character, agent persona, recurring identity.

## Brand boundary

OddHobb verbs: make, design, personalise, gift, print, wear, send.
Pogtown verbs: perform, play, talk, compete, host, watch, share, join.

## One identity graph, never two

No separate OddHobb user / Pogtown user, mesh / avatar. One identity
service: subject, mesh, voice, persona, relationships, memories — serving
both commerce and runtime.

## One plugin (for now)

OddHobb plugin with skills: oddhobb-onboarding, oddhobb-shopper,
oddhobb-designer, pogtown-performer, pogtown-games (later). Entry points:
OddHobb Studio, Pogtown Stage, Pogtown Arcade. ChatGPT never needs to know
it crossed backend products.

## Graduation

Pogtown becomes pog.town when it pulls on its own: feed, stages, games,
competitions, character pages, follows, rankings. Auth stays
"Continue with OddHobb". Nintendo-account model: character system, shop,
games/worlds. OddHobb is the toy factory; Pogtown is where the toys go
after midnight.

## Human-agent games (where Pogtown gets big)

`play(room, players=[human, mesh, agent...], ruleset)` emitting a live
session across humans, agents, characters and the engine. "Put Dad and my
ChatGPT character on a quiz show." That is definitely Pogtown.
