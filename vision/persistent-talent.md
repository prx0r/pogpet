# Persistent synthetic talent (founder, verbatim 2026-10-10)

> Graduation: Freaktown creates, audience validates, Influence brands.
> Freaktown owns who the character is; Influence owns where/how it appears.
> Four simultaneous states (fictional/public/empirical/commercial), kept
> separate and linked. Darwinian talent agency, not content network.

## Graduation ladder

```text
CHARACTER: draft → contestant → recurring → regular → breakout → public_persona
```

At `public_persona`, Influence creates a Character Brand:

```json
{
  "entity_id": "no-nose-nolan",
  "source": "freaktown",
  "character_version": 18,
  "channels": {"youtube": {}, "instagram": {}, "x": {}, "tiktok": {}},
  "voice_policy": "character_graph",
  "commercial_policy": {
    "brand_deals": "human_approval",
    "merch": "allowed",
    "paid_posts": "human_approval"
  }
}
```

Never let a character become whatever performed best on Instagram: canon,
beliefs, relationships, voice, history, behavioral rules stay in the
CharacterGraph; Influence gets a read-only public projection.

## Every platform is another experiment environment

Same character, changing medium: Shorts (retention/hooks), long-form
(narrative, interviews), Reels (visual identity), feed (still
attachment), X (written voice, topicality), podcasts (conversational
depth, improv), Pogtown (randomized control), live (synchronous
response), AR (embodiment + place), merch (economic attachment).

Podcasts/interviews: CharacterGraph + recent events + relationship to
interviewer + false beliefs + controversies + callbacks → continuity;
podcast events feed back as canonical events (Nolan claims he invented
airport security → committed → confronted later).

## Public memory vs character memory

Freaktown CharacterGraph = what the character believes/remembers.
Influence Public Graph = what audiences have seen/published. Never tweet
unestablished canon: check canonical? publicly established? safe to
reveal? consistent with current state?

## Autonomous social without generic bots

Posts come from valid character actions (react_to_event, misinterpret_
news, boast, defend_failure, attack_rival, reply_to_fan, continue_
callback, announce_investigation, complain_about_ella,
promote_appearance) — social-media JokeBlocks. Influence spots
opportunities; Freaktown realizes them in-character. Cross-platform
character interaction (Robot tweets → Nolan replies → Ella quote-tweets
→ Pigeon conspires) becomes evolving social world with reply lineage;
audience quotes feed future callbacks. Free Pogtown lore.

## Brand deals as in-world events

Nolan misunderstands the sponsorship; Corporate Robot treats talking
points as compliance. Separation: Influence owns contract/claims/
disclosure/dates/payment; Freaktown owns expression; qprivately gates
real deals under authorized contracts.

## AR as just another stage

Place + anchor + 90-second performance (Pigeon rant on a park bench,
Nolan at Heathrow, Robot in a lobby). Same graph, same runtime; spatial
layer supplies coordinates/scale/occlusion/camera/anchor. Stages:
Freaktown Stage, Web 3D, YouTube render, AR location, VR venue,
holographic install — all implement StageRuntime.

## Live levels 1–5

Pre-rendered → live interstitials → Ella interviews live → crowd-prompt
improv → multi-character improv holding graph state. Synthetic performers.

## Merch enters canon (cleanly layered)

Nolan's figure → "the department commissioned my statue" (his belief);
sellout ornament → "decorated for service" (his interpretation). Layers:
OddHobb (units sold) → CharacterGraph (optional fictional
interpretation) → Influence (publishes content).

## Evidence-based graduation (prestigious, not automatic)

Multiple appearances, character-specific positives, return requests,
recognizable name, quote adoption, cross-material performance →
independent audience demand → persistent accounts. Never every generated
Freak.

## The loop

Pogtown hypothesis → Freaktown experiments → response → market fit →
persistent graph → Influence identity → YouTube/Instagram/X/podcasts →
evidence → better theory + deeper character → AR/live → attachment →
OddHobb products → commercial evidence → reinvestment. Behind every
consequence: Influence → ReviewBundle → qprivately → authorization →
action → receipt.

## Four states, separate and linked

Fictional (beliefs), public (seen), empirical (what works), commercial
(demand). Characters persist years without engagement-mush collapse.
