# Print ladder: wrapping paper first (founder, verbatim 2026-10-10)

> Imported from chat. Founder's words kept as the gold reference for the

Yes — **wrapping paper is one of the best next Prodigi tests**.

In fact it's unusually well suited to the exact system you're building, because it uses the same core loop as cards:

```text
person/pet photos
→ constrained generated design
→ deterministic print surface
→ preview
→ checkout
```

No sizing.
No assembly.
No mesh.
No exact fit tolerances.
No "does this phone case fit iPhone 13 or 14 Pro Max?" nonsense.

## Best Prodigi products for this pipeline

Ranked:

### 1. **Wrapping paper** — probably the best next test

- single flat printable surface
- perfect for Christmas
- can look good with **simple repeat patterns**
- forgiving if the generation is a bit playful
- very giftable / easy to understand
- preview is straightforward

Core idea: **pet face in a Santa hat repeated across the paper**. Killer first version.

Three super-safe modes:

#### Mode A — repeat face pattern
- pet face cutout
- Santa hat
- candy canes / snowflakes
- repeated on coloured background

#### Mode B — face + name pattern
- "Milo's Christmas"
- "Bella's Nice List"
- "Merry Christmas from Teddy"

#### Mode C — illustrated badge repeat
- pet face inside ornament / wreath / postage stamp / "North Pole Approved" badge
- repeated across sheet

The AI only needs to generate the face cutout / stylised badge and maybe
a decorative repeat element. Then the renderer tiles it deterministically.

### 2. **Posters / art prints**

- one flat surface, easy preview, reuses card-style scenes
- higher perceived value than cards
- "funny dad wall poster", "pet movie poster", "family roast poster",
  "Best in Show" pet print, Dad as sports champion, family fake newspaper

Easiest non-card product after wrapping paper.

### 3. **Postcards / flat cards / mini cards**

- same pipeline as greeting cards, simpler than folded multi-panel
- great for packs: "pack of 10 pet Christmas postcards", family
  announcement postcard, thank-you cards with dog face

### 4. **Stickers / sticker sheets** (if the supplier mix covers it)

- pet/person face, no sizing, repeatable, easy upsell, stocking filler
- pet sticker sheet, Christmas gift-seal stickers, face-in-ornament
  stickers, "From the dog" gift labels

### 5. **Calendars**

- huge emotional value, many photos, great Christmas gift, fits the
  upload-photos → auto-generate thesis
- but: layout complexity, dates/month correctness, more preview surfaces
- strong once cards are stable

### 6. **Mugs**

- conceptually simple, great novelty
- but: cylindrical mockups, wrap alignment, handle-safe area, harder
  previews than cards/wrapping

### 7. **Cushions / soft furnishings**

- pet face + festive pattern works, visually fun, giftable
- but: more expensive, mockups matter more, subjective
- later, not first

## Unusually suited to OddHobb

Products where one characterised subject remixes across many surfaces:

- **A. Wrapping paper** — one subject becomes a repeating pattern instantly
- **B. Poster** — one subject becomes a scene
- **C. Greeting card** — one subject becomes a joke format
- **D. Gift tags / postcards / stickers** — one subject becomes an icon system

Sweet spot: single subject, single printable surface, strong novelty,
minimal production risk.

## Avoid for now

Apparel, phone cases, anything with size/model variants, multi-component
products, anything where precise physical fit matters, products where poor
cropping ruins the item.

## Why wrapping paper is especially good

Design logic is simpler than cards. A card needs front + inside + back +
message + shipping choice. Wrapping paper mostly needs hero motif +
repeat tile + sheet preview.

```text
Upload pet photos
→ choose "Christmas"
→ system picks best face
→ cut out / stylise face
→ add Santa hat
→ generate decorative tile
→ tile across paper
→ show 3 previews
→ buy
```

## 3 wrapping-paper products to do first

1. **Pet Santa Repeat** — face cutout + Santa hat + snowflakes/holly/stars
   on a colour choice. Cleanest, do this one first.
2. **Nice List Wrap** — face in circular badge + repeated "Official Nice
   List" + optional name.
3. **Family Face Chaos** — multiple members/pets repeated with festive
   icons, chaotic/funny.

## Product rule for now

Good next product if: single printable surface, no sizing, no assembly,
no complex fit, looks good from one or a few photos, preview can be
deterministic, gift value is obvious. Wrapping paper passes perfectly.
