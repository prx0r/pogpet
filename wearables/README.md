# oddhobb-wearables-engine

Drop-in v2 fitting/compiler package for `prx0r/pogpet`.

It turns arbitrary GLBs into product variants using a reusable asset library:

- premium hats that deform only at the brim;
- garments fitted through a low-detail convex-hull proxy;
- Meshy/imported hand props on semantic sockets;
- printable hardware such as cake-topper spikes and ornament loops.

Start with `docs/wearables-engine.md`.
